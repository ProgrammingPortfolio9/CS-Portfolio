### Project Reflection: Item Frequency Tracker

1. Project Summary: I built a C++ program for Corner Grocer that tracks how often items are bought. It reads a file, lets users search for items, and shows a histogram.

2. Successes: I did well with file input/output and created a backup file (`frequency.dat`) to save data.

3. Enhancements: I could make the code faster by using a `map` for searches and adding better error handling to keep it secure.

4. Challenges: Making the histogram asterisks line up was hard. I fixed it by using the `<iomanip>` library and checking C++ documentation.

5. Transferable Skills: Learning how to read/write files and show data visually will help in all my future coding classes.

6. Maintainability: I used clear variable names and small functions so the code is easy to read and update.
